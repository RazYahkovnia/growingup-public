# growingup-public

דפי התמיכה ומדיניות הפרטיות של האפליקציה "גדלים ביחד".

- `index.html` — דף התמיכה (Support URL)
- `privacy.html` — מדיניות פרטיות (Privacy Policy URL)

## איפה זה באוויר

הקבצים נמצאים ב-[RazYahkovnia/growingup-public](https://github.com/RazYahkovnia/growingup-public), ו-GitHub Pages מפרסם אותם מהענף `main`:

- תמיכה: https://razyahkovnia.github.io/growingup-public/
- פרטיות: https://razyahkovnia.github.io/growingup-public/privacy.html

כדי לעדכן: עורכים את הקובץ, עושים commit ו-push ל-`main`, ואחרי דקה-שתיים הדף מתעדכן.
